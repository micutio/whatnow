# Requirements Specification: Flutter Application (`whatnow_app`)

## 1. Scope of the System

This document establishes the functional and non-functional requirements for the `whatnow` Flutter application (`packages/app`), which provides a graphical user interface backed by `whatnow_core`.

## 2. Functional Requirements

### 2.1 Task List & Quick Actions

* REQ-APP-1: The home screen shall display open tasks in prioritised order using `whatnow_core`.
* REQ-APP-2: The user shall be able to add a new task via the primary action button and see it reflected in the open task list.
* REQ-APP-3: The user shall be able to toggle a task's completion checkbox to close the task and remove it from the open task list.
